# Ritm

Azərbaycan dilində şəxsi planlayıcı. Yeddi ekran var: Bu gün, Plan, Vərdiş, Fokus, Digər, Statistika və Ayarlar. Tapşırıqlar, vərdişlər və fokus nəticələri cihazda saxlanır.

## İşə salmaq

```sh
cd Ritm
npm ci
npm start
```

Terminaldakı QR kodu Expo SDK 54 ilə uyğun Expo Go ilə aç. Android emulyatoru üçün `npm run android`, iOS simulyatoru üçün `npm run ios`, brauzer üçün `npm run web` işlət.

`npm run typecheck` TypeScript yoxlamasını işə salır.
