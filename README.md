# DayFlow

Expo və React Native ilə hazırlanmış müasir gündəlik planlayıcı.

## Başlatmaq

```bash
npm install
npx expo start
```

Terminalda görünən QR kodu iPhone-da Expo Go ilə skan edin.

## İmkanlar

- Həftəlik tarix seçimi
- Gündəlik tapşırıqlar
- Tapşırıq əlavə etmə və tamamlama
- Avtomatik irəliləyiş göstəricisi
- iOS və Android üçün uyğun adaptiv dizayn
